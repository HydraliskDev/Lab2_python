## Задача 1. Кодовые слова Олега
oleg.py

Олег составляет таблицу кодовых слов для передачи сообщений, каждому сообщению
соответствует своё кодовое слово. В качестве кодовых слов Олег использует
4-буквенные слова, в которых есть только буквы **A, B, C, D, E, X, Z**, причём
буквы **X** и **Z** встречаются только на двух первых позициях, а буквы
**A, B, C, D, E** — только на двух последних. Сколько различных кодовых слов
может использовать Олег?

**Требование:** решить с использованием модуля `itertools`.

### Описание проделанной работы

1. Проанализировано условие: оно фактически фиксирует алфавит для каждой позиции слова.
   - Позиции 1 и 2 — только из множества `{X, Z}` — 2 варианта на позицию.
   - Позиции 3 и 4 — только из множества `{A, B, C, D, E}` — 5 вариантов на позицию.
2. Выбрана функция `itertools.product` — она строит декартово произведение
   нескольких наборов и является компактной заменой четырёх вложенных циклов.
3. Переданы четыре набора: `first, first, last, last` — по одному на каждую позицию.
4. `product` возвращает ленивый итератор, поэтому подсчёт ведётся через
   `sum(1 for _ in words)` — на каждый элемент выдаётся единица, затем они суммируются.

**Расчёт вручную:** 2 · 2 · 5 · 5 = **100**.

### Код программы

```

#!/usr/bin/env python3

# -*- coding: utf-8 -*-

from itertools import product

def task1():
"""Сколько 4-буквенных кодовых слов можно составить по условию."""
first = ['X', 'Z']                # позиции 1-2
last = ['A', 'B', 'C', 'D', 'E']  # позиции 3-4

words = product(first, first, last, last)
return sum(1 for _ in words)

print(task1())

```

### Результат работы

```

100

```

## Задача 2. сколько цифр 6 в семеричной записи
arifm7.py

Значение арифметического выражения

```

49¹⁰ + 7³⁰ − 49

```

записали в системе счисления с основанием 7. Сколько цифр **6** содержится
в этой записи?

### Описание проделанной работы

1. Реализована вспомогательная функция `to_base(n, base)` — перевод
   натурального числа `n` в систему счисления с основанием `base` классическим
   алгоритмом «деление с остатком»:

   - остаток `n % base` даёт очередную (младшую) цифру;
   - целая часть `n // base` становится новым `n`;
   - процесс повторяется, пока `n > 0`;
   - полученные цифры собираются (каждая новая цифра приписывается в начало).

2. Значение выражения вычислено напрямую: `49 ** 10 + 7 ** 30 - 49`.
3. Полученная семеричная запись передана методу `.count('6')` — он считает,
   сколько раз подстрока `'6'` встречается в строке.
4. Дополнительно решение проверено аналитически.

**Аналитическое пояснение.** Так как `49 = 7²`, выражение равно `7³⁰ + 7²⁰ − 7²`.
Далее `7²⁰ − 7² = 7²·(7¹⁸ − 1)`, а `7¹⁸ − 1` в семеричной записи представляет
собой 18 цифр `6` подряд. Умножение на `7²` добавляет два нуля справа и не меняет
количество шестёрок. Слагаемое `7³⁰` даёт единицу в старшем разряде и не влияет
на разряды с шестёрками.

### Код программы

```

#!/usr/bin/env python3

# -*- coding: utf-8 -*-

def to_base(n, base):
"""Перевод натурального числа n в систему счисления с основанием base."""
if n == 0:
return '0'
digits = '0123456789abcdefghijklmnopqrstuvwxyz'
result = ''
while n > 0:
result = digits[n % base] + result
n //= base
return result

def task2():
"""Сколько цифр 6 в 7-чной записи числа 49^10 + 7^30 - 49."""
value = 49 ** 10 + 7 ** 30 - 49
return to_base(value, 7).count('6')

print(task2())

```

### Результат работы

```

18

```

## Задача 3. Количество диапозон
312mln.py

Найдите среди целых чисел, принадлежащих числовому отрезку
`[312614; 312651]`, числа, имеющие ровно шесть различных натуральных
делителей. Для каждого найденного числа запишите эти шесть делителей
в шесть соседних столбцов на экране с новой строки. Делители в строке
должны следовать в порядке возрастания.

Например, в диапазоне `[12; 15]` ровно шесть различных натуральных делителей
имеет число 12, поэтому для этого диапазона вывод на экране должен содержать
следующие значения:

```

1 2 3 4 6 12

```

### Описание проделанной работы

1. Реализована функция `divisors(n)`, возвращающая все натуральные делители
   числа в порядке возрастания.
2. Перебор ведётся не до `n`, а до `√n`, поскольку делители образуют пары
   `(i, n // i)`, и меньший элемент пары не превосходит корня. Это ускоряет
   работу примерно в 560 раз для чисел данного диапазона.
3. Для каждой найденной пары добавляются **оба** делителя: `i` (маленький)
   и `n // i` (большой). Без добавления `i` потерялись бы все малые делители
   (1, 2, 3, …).
4. Проверка `i != n // i` защищает от дублирования делителя у полных квадратов:
   например, у числа 36 пара `(6, 6)` даёт только один делитель.
5. Сортировка `result.sort()` нужна, потому что делители обнаруживаются парами
   «маленький — сразу большой» и итоговый порядок не является возрастающим.
6. Основная функция `task3` перебирает числа отрезка через `range(start, end + 1)`.
   Конструкция `end + 1` обязательна: `range` не включает правый конец,
   а число `312651` должно проверяться.
7. Числа с `len(d) == 6` добавляются в список в виде кортежа `(число, делители)`.
8. Вывод через `' '.join(str(x) for x in d)` — делители склеиваются через пробел,
   как требует формат задачи.

**Теоретическая справка.** Ровно шесть делителей имеют числа вида `p⁵` или
`p²·q`, где `p` и `q` — различные простые числа. В заданном диапазоне реализуется
только второй случай, поскольку ни одна пятая степень простого числа в него
не попадает.

### Код программы

```

'''#!/usr/bin/env python3
# -*- coding: utf-8 -*-'''
def divisors(n):
    result = []
    i = 1
    while i * i <= n:
        if n % i == 0:
            result.append(i)
            if i != n // i:
                result.append(n // i)
        i += 1
    result.sort()
    return result
def task3(start = 312614, end = 312651):
    found = []
    for n in range(start, end + 1):
        d = divisors(n)
        if len(d) == 6:
            found.append((n, d))
    return found
for number, d in task3():
    print(' '.join(str(x) for x in d))

```
